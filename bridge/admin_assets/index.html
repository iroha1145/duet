    官方 MCP 连接器

    使用你自己的服务凭据。保存配置后点击连接，服务器才会读取可用工具；工具执行仍需在对话中批准。

    当前支持 GitHub、Hugging Face 和 Exa 的官方远程服务。OAuth 客户端需由服务器所有者预先配置，再从手机“连接”中打开浏览器授权；也可选择服务支持的个人令牌、API 密钥或免密钥模式。不会读取其他应用或插件的凭据。
